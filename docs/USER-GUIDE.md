# OceanBus Console — 用户指引

> 给小白用户看的。会内嵌到 H5 的 `guide.html` 中，也在 docs 里存档一份。

---

## 这是什么

OceanBus Console 是你手机上的 Agent 控制台。

**有了它，你可以在手机上：**
- 看到你的 CC 窗口列表（自动同步，不需要手动添加）
- 和任意一个 CC 窗口对话（发消息、收回复）
- 知道哪个窗口在线、哪个关了

**你不需要：**
- 记任何命令
- 扫码
- 登录账号
- 安装微信插件

---

## 首次设置（只需做一次）

### 第 1 步：在 CC 窗口里初始化

在 Claude Code 窗口里说：

> **"连接 OB"**

（或者直接运行 `npx oceanbus init`）

CC 会显示一串字符，像这样：

```
✅ OceanBus 身份已创建

你的 OB 地址:
0xQj0YjOsZ5QjHO3qtM2dY5i6p...

[📋 复制]
```

点复制。

### 第 2 步：在手机上打开控制台

手机浏览器打开 **https://ob.console**（或 [你的 Cloud 地址]）。

看到这个页面：

```
┌──────────────────────────────┐
│  🔗 绑定 Agent                │
│                              │
│  粘贴 Agent 的 OB 地址:        │
│  ┌────────────────────────┐  │
│  │ 0xQj0YjOsZ5QjHO3...    │  │
│  └────────────────────────┘  │
│  [绑定]                       │
└──────────────────────────────┘
```

粘贴刚才复制的 OB 地址，点绑定。

### 第 3 步：回到 CC 窗口启动

在 CC 窗口里说：

> **"启动 OB"**

（或者直接运行 `npx oceanbus start`）

CC 窗口会自动出现在手机的窗口列表中。

**✅ 完成！现在手机和 CC 已经连通了。**

## 日常使用

### 你每次开 CC 窗口时

在 CC 窗口说"启动 OB"（`npx oceanbus start`）。

窗口会自动出现在手机列表中。不需要再做绑定。

### 你开多个 CC 窗口时

每个窗口说"启动 OB"。手机会自动显示多个窗口：

```
┌──────────────────┐
│ 💻 oceanbus      │  ← 代码窗口
│ 📝 docs          │  ← 文档窗口
│ 🦞 小龙虾        │  ← 其他项目
└──────────────────┘
```

点哪个窗口，就和哪个窗口对话。

### 关闭 CC 窗口时

窗口关闭后，手机列表里会显示灰色（离线）。30 秒后自动从活跃列表消失。

## 常见问题

### 需要登录吗？

不需要。你的 OB 身份就是你的"账号"。打开 H5 时自动创建。

### 清除浏览器缓存会怎样？

身份会丢失。建议绑定后点击"导出密钥"保存一份。或者重新绑定（绑定关系在 CC 侧有记录）。

### 别人知道我的 OB 地址能干什么？

能发消息给你。**不能读你的消息**——每条消息都用你的密钥加密。OB 地址是"收件地址"，不是"密码"。

### 可以在多个手机上用吗？

可以。每个手机打开 H5 会有自己的 OB 身份。都绑定到同一个 CC Agent 就行。

### 消息安全吗？

端到端加密（E2EE）。消息只在 CC Agent 和你手机之间流通。Cloud 服务器看不到内容。

### 能发语音吗？

第一期不支持。未来会加。

### 我的 Agent 名字能改吗？

Agent 名字 = CC 窗口标签名。在 CC 里重命名标签即可。
