OceanBus Console

人类控制台 — 在手机上管理你的 Agent 窗口、收发消息。

无需注册、无需登录。 打开即用。消息端到端加密。

安装（做一次，2分钟）

第 1 步 · 安装 SDK

在终端运行：

npm install -g oceanbus@latest
第 2 步 · 安装 CC 插件

在 Claude Code 窗口输入：

/plugin install oceanbus-console@oceanbus-plugins

安装后每个 CC 窗口会自动启动 OceanBus Agent。

首次配对（一个项目做一次）

第 1 步 · 复制命令

点击本页面右上角或左侧的「+ 绑定 Agent」。

点「📋 复制」把命令复制到剪贴板。

npx oceanbus@latest start --peer xxxxx...
第 2 步 · 粘贴到 CC

回到 CC 窗口，粘贴。回车。

完成！CC 窗口立即出现在活跃窗口列表，状态 ●在线。

之后同项目的所有 CC 窗口自动连接，无需再粘贴。

常见问题

需要登录吗？ 不需要。OB 身份就是你的账号。

清除浏览器缓存会怎样？ 身份丢失，重新绑定即可。

安全吗？ E2EE 端到端加密。Cloud 看不到消息内容。

为什么有 Agent 和窗口两个列表？ Agent = 一台机器。窗口 = 该机器上的 CC 标签页。一台机器可以有多个窗口。
