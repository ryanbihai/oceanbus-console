📡 OceanBus Console

人类控制台 — 在手机上管理你的 Agent、与 CC 窗口对话。

🔒 无需注册、无需登录。
你的 OB 身份就是你的账号。消息端到端加密。

🚀 首次设置（3 步，5 分钟）

第 1 步 · Agent 侧

在 Claude Code 窗口里运行：

npx oceanbus init

记下输出的 OB 地址。

第 2 步 · 手机侧

打开 OceanBus Console。

点击 「🔗 绑定新 Agent」。

在 Agent 终端运行显示的配对命令（或手动输入配对码）。

第 3 步 · 确认

Agent 终端运行命令后，Console 会自动显示绑定成功。

以后每次打开 CC 窗口，运行：

npx oceanbus start

窗口会自动出现在 Console 的活跃列表中。

💡 常见问题

Q: 需要登录吗？
A: 不需要。打开页面即用。

Q: 清除浏览器缓存会怎样？
A: 身份丢失，重新绑定即可。绑定关系在 Agent 侧有记录。

Q: 别人拿到我的 OB 地址能做什么？
A: 能发消息给你。不能读你的消息（端到端加密）。OB 地址是收件地址，不是密码。

Q: 为什么有两个 Agent 列表？
A: 「Agent 列表」是绑定的机器（一台电脑 = 一个 Agent）。「活跃窗口」是该机器上打开的 CC 窗口。你可以绑定多台机器。

Q: 窗口离线了还能发消息吗？
A: 可以。消息会缓存在 OB mailbox 中，窗口重新上线后自动收到。
